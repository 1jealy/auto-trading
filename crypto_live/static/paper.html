    뒤처짐이 0.05%p를 넘고 해외가 +0.10% 넘게 오르면 #18이, 0.20%p·+0.35%면 #17이 삽니다.

      비용 측정용 · 손실 예상

      해외가 3초에 +0.10% 오르고 업비트가 0.05%p 넘게 뒤처지면 100만 원을 사서 20초 뒤 팝니다.

      #17 틈 단타 (정식)

      채점 대상

      해외가 3초에 +0.35% 오르고 업비트가 0.20%p 넘게 뒤처지면 500만 원을 삽니다. +0.25% 익절, −0.30% 손절, 길어야 60초.

      느린 전략 하루·주에 한 번 판단 · 꺼져 있던 날도 빠지지 않음

      계좌 가치

        실제 호가로 잰 비용 1분마다 · 최근 7일

        사자마자 되팔면 잃는 비율

        수수료는 빼고 호가 때문에 잃는 몫만 (가운데 값). 코인 전략 계산에는 왕복 0.20%를 가정으로 넣었습니다. 이 표가 그보다 작아야 가정이 넉넉한 것입니다.

        엔진이 1분 넘게 켜져 있으면 쌓여요

        준비 중 아직 시작하지 않은 실험

        #15 DART 숫자 공시 스윙

        큰 공급계약·자사주 소각·실적 급증 공시가 난 종목을 다음 날 아침에 사서 10거래일 보유

        • DART API 키 발급 (opendart.fss.or.kr, 무료) → .env의 DART_API_KEY
        • 공시 문서 안의 표를 읽는 코드 (LLM 없이 규칙으로)
        • 상장폐지 종목을 포함한 과거 백테스트 먼저

        #16 LLM 뉴스 스윙

        새로운 호재 기사만 골라 5거래일 보유. 과거 시험은 못 하고 모의 기록으로만 판단

        • 뉴스를 어디서 받을지 결정 (이용 약관 확인)
        • LLM 키와 비용 결정, 질문 문장·모델을 시작 날 고정
        • 비슷한 기사 묶는 규칙
