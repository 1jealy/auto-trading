# 자동매매 연구 계획 (#12 ~ #18)

2026-11-15 작성. 사용자가 가져온 "마스터 플랜(#12~#17)"을 검토해 고칠 곳을 고친 판이다.
정확한 규칙·숫자는 `docs/experiments.md`의 각 실험 항목이 기준이고, 이 문서는 전체 그림과 **왜 고쳤는지**를 적는다.

## 0. 원칙 (바뀌지 않음)

- 규칙과 합격 기준은 결과를 보기 전에 `docs/experiments.md`에 적는다. 결과를 보고 고치면 새 시도로 센다.
- 비용(수수료·체결 손해·세금)은 항상 넣고, 실제보다 넉넉하게 잡는다.
- 다시 하지 않는 것:
  - 한 거래소 가격만 보는 비트코인 1분~1시간 단타 (#5·#6·#7·#10 모두 탈락)
  - LLM으로 과거 뉴스 백테스트 (LLM이 그 뒤 주가를 이미 알고 있을 수 있음)
  - 뉴스 1초 반응 초단타 (속도 경쟁, 검증 불가)
- **실전 주문 기능과 주문용 API 키는 붙이지 않는다.** 지금은 전부 모의(가짜 돈)다.
- 관찰할 때는 "같은 날이 몇 번 세어졌나"와 "상위 며칠을 빼면"을 함께 본다 (#10의 교훈).

## 2. 가져온 계획에서 고친 것

### 꼭 고쳐야 했던 것

1. **#17의 "호가 차이 0.05% 이하" 조건은 비트코인 말고는 거의 통과할 수 없었다.**
   2026-11-14에 잰 값으로 가격 한 칸(틱) 크기가 리플 0.07%, 이더리움 0.04~0.08%, 솔라나 0.05%다.
   호가 차이는 한 칸보다 작을 수 없다. → **"0.05% 이하이거나 딱 한 칸"**으로 고쳤다.
2. **"계속 거래되는 단타"는 #17과 따로 #18로 만들었다.** #17 기준(해외 3초에 +0.35%)은 코인당 하루 2~6번뿐이다
   (바이낸스 현물 1초 봉 12시간으로 빈도만 셈, 수익은 안 봄). 기준을 +0.10%로 낮추면 코인당 하루 250~700번이다.
   기준을 낮춘 쪽은 비용(왕복 0.1% + 호가 차이)을 넘기 어렵다고 예상하지만, **실제 체결 비용을 계속 재는 용도**로 가치가 있다.
3. **느린 전략(#12·#13·#14)은 "3~6개월에 독립 사건 100건"을 채울 수 없다.** 주 1회·하루 1회 판단이라 6개월에 거래가 몇 번~수십 번이다.
   → 이 셋은 6개월에 중간 점검(기록만), **12개월에 판정**한다. 그 전에 백테스트를 참고로 본다.
4. **#14의 코인 4개는 "지금 살아남은 큰 코인"이라 과거 백테스트가 좋게 나온다**(솔라나는 업비트에 2021-10 상장).
   → 과거 백테스트는 2018년 초에도 시가총액 1~3위였던 **비트코인·이더리움·리플 3개로만** 하고, 4개짜리는 모의 투자로만 판단한다.
5. **#12의 금 ETF(411060)는 2021-12 상장이라 과거가 4년뿐이다.** 그리고 2015~2026년 ETF 데이터는 #1·#9에서 이미 봤고,
   "120일"은 60일이 실패한 걸 본 뒤 고른 숫자다. → 백테스트는 참고로만 하고(금 없는 4개로 2015~, 금 포함 5개로 2022~), 판정은 모의 투자로 한다.
6. **#13은 숫자가 7개나 된다**(펀딩비 기준 2개, 김치 프리미엄 기준 2개, 평균 기간, 여유 폭, 90일). 맞춰 넣기 쉬운 구조이고
   바이낸스 펀딩비는 2019-09부터만 있어 그 기간 비트코인은 전부 이미 봤다. → 백테스트는 참고, 판정은 모의 투자.
7. **코인 전략의 "실측 호가 비용"은 계산에 바로 쓰지 않는다.** 결과를 보고 비용을 바꾸는 셈이 되기 때문이다.
   → 계산은 고정 가정치(수수료 0.05% + 체결 손해 0.10% = 한쪽 0.15%)로 하고, 실제 호가로 잰 비용은 **따로 기록해 가정이 넉넉한지 확인**한다.
   단타(#17·#18)는 매번 실제 호가창으로 체결가를 계산한다.
8. **`.claude/settings.local.json`이 아니라 `.claude/settings.json`에 넣는다.** local 파일은 Git에 안 올라가서 클라우드 세션에 적용되지 않는다.
   `ruff`는 이 프로젝트에 설치돼 있지 않아 허용 목록에서 뺐다.

### 알아 둘 약점 (규칙은 그대로 둠)

- **#17 익절 +0.25% / 손절 −0.30%:** 업비트 수수료(왕복 0.1%)를 빼면 이기면 +0.15%, 지면 −0.40%다. 10번 중 7~8번을 이겨야 본전이다(#6이 이 모양으로 무너졌다).
- **#17 "200ms 지연":** 실제 지연은 그때그때 잰 값을 기록한다. 호가를 200ms 뒤에 요청하고, 응답이 더 늦으면 그 늦은 호가로 체결한다.
- **코인원 수수료 0%:** #5 때의 가정이다. 지금도 맞는지 확인이 필요해서 화면에 "가정"이라고 표시한다.
- **#15:** 공급계약·자사주 소각·잠정 실적은 DART에 정해진 양식으로 올라오지만 **API 숫자 칸이 아니라 공시 문서 안의 표**다.
  LLM 없이 규칙으로 읽을 수 있지만 문서 읽는 코드를 따로 만들어야 한다. 증권거래세는 연도마다 달라(2026년 0.20%는 확인 필요) 과거 계산에는 그 해 세율을 써야 한다.
  상장폐지 종목을 꼭 포함해야 한다.
- **#16:** 뉴스를 어디서 받을지(이용 약관)와 LLM 키·비용이 정해져야 한다. 비슷한 기사 묶기는 별도 임베딩 모델 대신 제목 글자 겹침 같은 규칙으로 시작하는 편이 단순하다.
  `temperature=0`이어도 답이 매번 같다는 보장은 없으므로 모델 이름과 답 원문을 그대로 저장한다.
- **#12:** 흔들림에 반비례로 담으면 채권·달러 비중이 60% 안팎이 된다. 수익률이 아니라 흔들림 대비 수익으로 봐야 한다. 채권·해외·금 ETF 매매차익 세금(15.4%)은 반영하지 않는다.
- **여러 전략을 한꺼번에 시험하면 하나쯤은 우연히 좋게 나온다.** 그래서 합격선을 t값 2.5로 올렸고, 통과해도 한 번 더 확인한다.

## 3. 어디서 돌리나

- 엔진은 **켜 둔 컴퓨터**에서 돈다. `코인시세.bat` / `코인모니터_폰연결.bat`을 실행하면 서버와 엔진이 함께 켜진다.
- 하루·주 단위 전략(#12·#13·#14·대조군)은 **시작일 이후 시세로 매번 다시 계산**하므로 컴퓨터가 꺼져 있던 날도 빠지지 않는다.
- 단타(#17·#18)와 호가 비용 기록은 **켜져 있던 시간만** 기록된다. 켜져 있던 시간을 함께 저장한다.
- 해외 기준 가격은 **OKX 선물**(2026-11-15 시작 전 바이낸스에서 변경). 바이낸스 선물은 미국 등에서 막히기 때문이다.
  OKX 에 연결되지 않아 바이낸스로 대신한 기록은 따로 표시하고 정식 판정에 넣지 않는다.
- 기록은 `data/paper/`에 쌓인다(Git에 안 올라감). **따로 백업할 것.**

## 4. 일정과 합격 기준

| 언제 | 무엇을 |
|---|---|
| 지금 | #12·#13·#14·#17·#18 모의 투자 시작, 대조군 기록 시작 |
| 다음 차례 | #12·#13·#14 과거 백테스트(참고용, 위 2-4~2-6의 제한 포함). #15는 끝남(탈락) |
| 가동 1~2주 | 단타 기록을 눈으로 대조(감사 기록 화면), 지연·호가 비용 확인 |
| 2~4주 | #17 판정: 정식 거래 100건 이상일 때. 모자라면 최대 8주까지 연장, 그래도 모자라면 "신호 부족"으로 종료 |
| 6개월 | #12·#13·#14 중간 점검(기록만) |
| 12개월 | #12·#13·#14 판정 |

**단타(#17) 합격 기준 — 넷 다:**
1. 업비트 비용(수수료 왕복 0.1% + 실제 호가 체결)을 뺀 건당 평균 > 0
2. 건당 수익의 t값 ≥ 2.5
3. 가장 많이 번 3일을 빼고도 건당 평균 > 0
4. 기간을 반으로 나눠 앞·뒤 모두 건당 평균 > 0

#18도 같은 네 기준(사건 200번). 단타 채점은 모두 **사건 단위**(60초 안에 이어진 신호는 한 번으로 셈).

**느린 전략(#12·#13·#14) 합격 기준 — 12개월에 둘 다:**
1. 수익/흔들림 비율이 대조군(#12는 ETF 4개 나눠 담기, #13·#14는 비트코인 그냥 보유)보다 높을 것
2. 가장 크게 떨어진 폭이 대조군보다 작을 것

통과한 전략도 바로 실전에 넣지 않는다. 한두 달 더 지켜본 뒤 아주 작은 금액부터 검토한다.
